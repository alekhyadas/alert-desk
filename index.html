One-time setup. The token stays in this browser only (localStorage) and talks directly to GitHub, nothing in between.

How to create the token

GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token. Repository access: Only select repositories, pick stock-alerts. Permissions: Contents = Read and write, Actions = Read-only. Set an expiry you're comfortable with, then paste the token here.
